Learn through investigation

Practical troubleshooting is part of the course.

Each lab connects a symptom to the network concept behind it, then uses evidence to narrow down the cause.

Addressing & routing

“The server cannot reach the destination.”

Inspect the interface, address, selected route, gateway, and return path.

ip -br addrip route getip neigh
Name resolution

“The name fails, but the IP works.”

Follow the hostname lookup and compare DNS results with the expected destination.

getent hostsdig
Service connectivity

“The process is running. The port is unreachable.”

Check the listening address, port, route, and traffic controls.

sscurl -v
HTTPS & applications

“TCP connects, but HTTPS fails.”

Separate certificate, TLS, HTTP, redirect, and application errors.

curl -vopenssl s_client
Cloud & Kubernetes

“The backend is healthy, but users cannot connect.”

Trace listeners, health checks, routes, access rules, and service paths.

route tablesbackend healthservice DNS
AI & API traffic

“The request connects, then times out.”

Inspect timing across DNS, connection setup, TLS, streaming, and the application.

curl timingsrequest tracesproxy logs

Clear technical English
