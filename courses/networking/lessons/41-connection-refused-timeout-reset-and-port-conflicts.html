Understand the idea

Learning target: Turn a connection symptom into testable possibilities without treating one message as a complete diagnosis.

Error messages narrow possibilities

Connection refused often means a reachable endpoint returned a rejection, commonly because no matching listener exists. A timeout means the expected progress was not observed before a deadline. It can result from drops, missing paths, overloaded components, or application delay depending on the stage. A reset means an endpoint or intermediary aborted the TCP connection.

Identify which stage failed

A connect timeout differs from a read timeout after setup. An HTTP error response differs from either. Record the exact tool message and timing. A symptom is evidence, not a one-to-one map to a single root cause. Captures at more than one point can distinguish traffic that never arrived from traffic whose response was lost.

A bind conflict is local

Address already in use indicates a local binding collision under the relevant address-family and socket rules. Another process can own the desired port. Identify its purpose and configuration before stopping it. Automatically killing an owner can break another service while leaving the original configuration problem unresolved.

Practical troubleshooting

Symptom

An application reports Address already in use.

Evidence that narrows the cause

A local socket conflicts with its requested bind; inspect the owner and family.

Next action and verification

Resolve the configuration deliberately and test both affected services.

Retest the original operation from the same source context. A successful test of a different endpoint or protocol does not establish that this symptom is resolved.
