Understand the idea

Learning target: Compare the purpose of IPv6 neighbour discovery with the IPv4 mechanisms already learned.

IPv6 uses Neighbor Discovery instead of ARP

Neighbor Discovery uses ICMPv6 messages for several local-link functions. Neighbour Solicitation and Neighbour Advertisement support address resolution and reachability. Router Solicitation and Router Advertisement help hosts learn router and prefix information. These are control-plane functions required by ordinary IPv6 communication.

Multicast and link scope are part of the model

IPv6 has no broadcast address type. Discovery uses appropriate multicast groups and local-link handling. Link-local router addresses can be valid next hops for globally addressed traffic because the next hop belongs to the directly attached link. The IP destination of the packet remains the remote endpoint.

Filtering can break more than ping

Blocking ICMPv6 indiscriminately can prevent discovery or Path MTU feedback, even when application TCP ports appear allowed. Inspect the failed function and message types. Duplicate Address Detection is another relevant local-address function; an address in a tentative or duplicate-related state is not equivalent to an ordinary ready address.

Work through one example

A host reaches a global IPv6 service through a link-local gateway.

  1. The route chooses a gateway such as fe80::1 on a specified interface.
  2. The host resolves that next-hop neighbour on its link.
  3. The globally addressed packet is carried to the local router; its remote destination does not become fe80::1.

Practical troubleshooting

Symptom

IPv6 fails after all ICMPv6 traffic was blocked.

Evidence that narrows the cause

Check discovery and packet-too-large feedback rather than assuming only echo traffic was affected.

Next action and verification

Permit the required protocol control traffic according to the network policy.

Retest the original operation from the same source context. A successful test of a different endpoint or protocol does not establish that this symptom is resolved.
