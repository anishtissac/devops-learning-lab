Understand the idea

Learning target: Follow address configuration and distinguish an address lease from routes and resolver settings.

DHCP supplies configuration through a lease

DHCPv4 can provide an address lease and options such as subnet mask, routers, and DNS resolvers. The common initial exchange is Discover, Offer, Request, and Acknowledge. A relay can help a client reach a server beyond its local broadcast domain. Renewal behaviour differs from an initial unconfigured-client exchange.

A lease has a lifetime

The client uses the offered configuration according to lease state and renewal rules. A recorded lease file does not prove the current link or application path works. A client can also retain an address while later resolver or route configuration differs from expectations. Inspect the effective host state as well as the source of configuration.

Avoid unrelated renewal experiments on important hosts

Renewing or releasing a production lease can disrupt access. For learning, inspect configuration and logs or use the browser exchange model. IPv6 has its own address and router-discovery mechanisms; DHCPv4's four-step story is not a complete explanation of every IPv6 setup.

Work through one example

A lab client requests its first address.

  1. Discover asks for service; Offer proposes configuration.
  2. Request identifies the requested lease; Acknowledge confirms it.
  3. The client applies configuration and later renews according to lease rules. Each resulting address, route, and resolver still needs verification.

Practical troubleshooting

Symptom

The client has an address but cannot resolve names.

Evidence that narrows the cause

Inspect supplied resolver configuration and reachability independently of the lease address.

Next action and verification

Repair the failed resolver path rather than assuming the address itself is invalid.

Retest the original operation from the same source context. A successful test of a different endpoint or protocol does not establish that this symptom is resolved.
