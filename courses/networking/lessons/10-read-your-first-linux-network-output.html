Understand the idea

Learning target: Interpret interface names, interface state, addresses, and prefixes in ip output.

Read one interface at a time

Start with ip -br link to identify attachment points and link state. Then use ip -br addr to read addresses and prefixes. The compact format is useful for an inventory. Detailed ip addr output adds scope, flags, and lifetimes that may matter when a short display leaves questions unanswered.

Understand the fields before drawing conclusions

In an example such as enp0s9 UP 10.0.1.87/28, enp0s9 is the interface name and 10.0.1.87 is an assigned address. The /28 is a prefix length. UP in a compact display is state information; it is not a test of a remote website. An interface can also have a link-local IPv6 address alongside its IPv4 address.

Use a destination-specific lookup

ip route shows routing information. ip route get asks the kernel how it would route a selected destination under the supplied lookup context. The result may show via for a gateway, dev for an interface, and src for a chosen source address. The lookup does not transmit a probe or prove the destination responds. More advanced policy routing can require additional lookup context.

See the relationships

Work through one example

Read: 192.0.2.20 via 10.0.1.81 dev enp0s9 src 10.0.1.87.

  1. 192.0.2.20 is the chosen destination, not another local interface address.
  2. 10.0.1.81 is the next-hop gateway and enp0s9 is the outgoing interface.
  3. 10.0.1.87 is the selected source in this lookup. The result describes a decision, not a completed connection.

Practical troubleshooting

Symptom

Someone reports that ip route get succeeded, so the application must work.

Evidence that narrows the cause

The command reports a route decision without testing service reachability.

Next action and verification

Follow it with an appropriate application connection test and inspect the response.

Retest the original operation from the same source context. A successful test of a different endpoint or protocol does not establish that this symptom is resolved.
