Understand the idea

Learning target: Read compressed IPv6 notation and understand how prefixes work with 128-bit addresses.

IPv6 notation represents 128 bits

A full IPv6 address has eight groups of four hexadecimal digits. Each group holds sixteen bits. Leading zeroes in a group may be omitted. A single double colon can compress a sequence of zero groups. It can appear only once, otherwise the number of omitted groups becomes ambiguous.

Prefixes still count from the left

An IPv6 /64 fixes the first 64 bits and leaves 64 address bits after the prefix. That is not an IPv4-style host-capacity calculation with a broadcast address removed: IPv6 does not have broadcast. A /128 identifies one address, while a /0 is the default IPv6 prefix. Subnet sizes must suit the IPv6 mechanisms used by the deployment; do not copy IPv4 sizing habits blindly.

Scope and notation both matter

2001:db8::/32 is reserved for documentation, so examples here are not live service destinations. A link-local address such as fe80::1 can exist on different links, and an interface scope can disambiguate it. In a URL, an IPv6 literal is enclosed in square brackets before a port, for example http://[::1]:8080/.

Work through one example

Expand 2001:db8:10::25.

  1. The three written groups before :: and one after it account for four groups.
  2. Four zero groups must be inserted to reach eight groups.
  3. The full address is 2001:0db8:0010:0000:0000:0000:0000:0025.
