Understand the idea

Learning target: Compare the two address families and introduce static and automatic address configuration.

Two address families

IPv4 uses 32-bit addresses, often written as four decimal octets. IPv6 uses 128-bit addresses written in hexadecimal groups with compression rules. They are different protocol families. A dual-stack host can run both. Successful IPv4 access does not prove that an IPv6 route, listener, or traffic rule is correct.

Configuration can be static or automatic

A static address is supplied through deliberate configuration. DHCP can supply leased IPv4 configuration. IPv6 can use mechanisms such as Router Advertisements and Stateless Address Autoconfiguration; DHCPv6 can supply additional configuration depending on the deployment. Do not assume every automatic IPv6 address came from DHCP, or that an address lease alone proves a default route exists.

Keep address, route, and resolver separate

A useful network setup often needs an address and prefix, a route for the destination, and a way to resolve names when names are used. These are related configuration items. A host can have an address and still lack a usable route. A route can work while a resolver fails. Diagnose the failed function rather than treating all configuration as one switch.
