Understand the idea

Learning target: Explain packet-size limits and investigate why small transfers may work while larger ones fail.

MTU is a size limit on a link

The IP MTU limits the size of an IP packet that can be carried over a link without exceeding that link's IP packet limit. Do not confuse it with a TCP application write size or the complete physical frame including all link overhead. Tunnels can reduce the effective room available to the inner packet.

IPv4 and IPv6 handle oversize traffic differently

An IPv4 router can fragment eligible packets when fragmentation is permitted; with Don't Fragment set, an oversized packet is dropped and appropriate ICMP feedback can report the limit. IPv6 routers do not fragment forwarded packets. Senders need suitable packet sizes, with ICMPv6 Packet Too Big feedback supporting adaptation.

Path MTU concerns the whole path

The smallest relevant link limit can constrain end-to-end packet size. TCP normally segments a byte stream using MSS and path information, so a large application message does not require one equally large IP packet. If size feedback is blocked, small exchanges can work while larger transfers stall. This pattern suggests a size-dependent path problem but still needs evidence.

Work through one example

An IP packet is 1500 bytes and the next-link MTU is 1280.

  1. The packet is too large for that link.
  2. If it is IPv6 or IPv4 with DF set, the forwarding router cannot simply forward it unchanged.
  3. Feedback can let the sender reduce size. Blocking the feedback can produce a black-hole symptom.

Practical troubleshooting

Symptom

Handshakes work but larger transfers stall.

Evidence that narrows the cause

Compare packet sizes, retransmissions, tunnel overhead, and ICMP size feedback.

Next action and verification

Correct the path MTU or feedback policy based on evidence rather than disabling unrelated security controls.

Retest the original operation from the same source context. A successful test of a different endpoint or protocol does not establish that this symptom is resolved.
