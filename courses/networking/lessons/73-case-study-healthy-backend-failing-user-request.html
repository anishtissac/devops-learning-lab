Understand the idea

Learning target: Check the full cloud or cluster entry path, intermittent behaviour, and what health checks miss.

Case: the probe and user request exercise different paths

A load-balancer health check can target an internal address, one port, and a simple path while users enter through another listener and name. In Kubernetes, a readiness result can make a Pod eligible while an external host/path route still points to another Service. A healthy badge must be translated into the exact test it represents.

Trace the selected backend for the real request

Record client DNS, destination family, listener, TLS identity, host/path match, selected backend set or Service, endpoint, target port, and dependency. Compare logs using a request identifier and time. If only some requests fail, test target differences, connection reuse, and path-specific behaviour rather than averaging away the failures.

Separate readiness from full workflow correctness

A probe might not call the database or model endpoint needed by the user operation. Conversely, making a health probe overly dependent on everything can exclude all backends during a shared dependency failure. Health-check design is an explicit trade-off; the troubleshooting task is to understand what the existing signal proves.

Verify from the original entry point

A successful direct Pod or backend request bypasses the entry path. It is useful comparison evidence, not final verification of the user operation. Retest the real hostname, TLS identity, method, path, and representative workload after the correction.

Practical troubleshooting

Symptom

A direct backend request succeeds, but the original user request still fails.

Evidence that narrows the cause

The successful test bypassed one or more relevant entry boundaries.

Next action and verification

Inspect the bypassed listener, identity, route, or policy and verify at the original entry point.

Retest the original operation from the same source context. A successful test of a different endpoint or protocol does not establish that this symptom is resolved.
