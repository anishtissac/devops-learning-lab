Understand the idea

Learning target: Compare getent, dig, resolver settings, curl output, and openssl s_client evidence.

Keep lookup and identity tests separate

A failed hostname request can begin with a lookup problem, connect to an unexpected address, or fail certificate validation after connecting. Collect each stage's output. getent follows the configured host lookup path; dig asks DNS. Different answers can expose local overrides, cache state, split-horizon views, or family selection.

Preserve the intended hostname during an IP-specific test

For HTTPS, the name influences virtual service selection and identity verification. curl --resolve can pin an address for a specific name and port while retaining the URL hostname. It is a controlled diagnostic override, not a DNS change for every application. Use it only with your own expected address and endpoint.

Read certificate evidence deliberately

openssl s_client can inspect a TLS handshake and chain. Supply -servername for the expected SNI name, and use appropriate hostname and trust checks when validating identity. Successful output fragments do not necessarily establish that every verification policy passed. Record the verification result and the original client error.

Work through one example

DNS returns an outdated address for an HTTPS service.

  1. Compare the normal request with the expected endpoint address.
  2. A controlled --resolve test keeps the intended hostname while bypassing normal lookup for that request.
  3. If only the override works, inspect resolver and cache state; still verify that the alternate endpoint is actually correct.

Practical troubleshooting

Symptom

Direct-IP testing reports a name mismatch.

Evidence that narrows the cause

The certificate may cover the intended DNS name rather than the numeric address.

Next action and verification

Retain the correct identity in the test and investigate the underlying lookup separately.

Retest the original operation from the same source context. A successful test of a different endpoint or protocol does not establish that this symptom is resolved.
