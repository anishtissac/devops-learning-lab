Gateways and IP forwarding

Understand the idea

Learning target: Follow a packet beyond the local network and distinguish host routing from router forwarding.

A gateway is the next router for a selected path

When the destination is beyond a directly attached network, a route can identify a next-hop gateway. The sender delivers the local frame to that gateway while retaining the remote IP destination. A default gateway is used when the routing rules choose a default route, not for every packet without exception.

Forwarding is a separate host function

A Linux system can originate its own traffic without forwarding traffic for other hosts. Acting as a router requires appropriate forwarding configuration, routes, and filtering. Merely adding two interfaces does not guarantee that transit packets will cross between them.

Every step needs a valid next decision

The gateway must have an outgoing route, and the destination side needs a way back to the original source or translated source. A correct sender route is only the first decision in the path. TTL or Hop Limit bounds forwarding and helps prevent packets circulating forever through a routing loop.

See the relationships

Work through one example

Host A sends from 10.0.1.10 to 10.0.2.20.

  1. A connected route handles 10.0.1.0/24; a gateway route handles the destination network.
  2. The host sends the first frame to 10.0.1.1.
  3. The gateway forwards toward 10.0.2.20 if its routes and controls allow it. The return must also be routed.

What to inspect

The sysctl reads IPv4 forwarding configuration. Reading it does not change the host.

Practical troubleshooting

Symptom

Both router interfaces work locally, but transit traffic fails.

Evidence that narrows the cause

Check forwarding state, transit filtering, and routes in both directions.

Next action and verification

Correct the intended router configuration after locating the failed forwarding condition.

Retest the original operation from the same source context. A successful test of a different endpoint or protocol does not establish that this symptom is resolved.
