Understand the idea

Learning target: Connect the physical network adapter to the interface that the operating system exposes.

Adapter and interface are related concepts

A network interface is an operating-system attachment point for sending and receiving network traffic. A physical network adapter can expose an interface to the host. Virtual machines and containers can use interfaces implemented through virtual devices. The operating system presents interfaces so that the network stack has a consistent way to work with different hardware and software paths.

An interface has several independent properties

Its name identifies it within its network namespace. It can have a link-layer address, an administrative state, an observed link state, an MTU, and zero or more IP addresses. Turning an interface administratively up does not create a working cable or assign an address. An interface can carry link-layer traffic even when it has no IPv4 address.

Read identity separately from configuration

Linux names such as eth0 or enp0s9 are interface names, not IP addresses. They depend on naming policy and environment. A cloud VNIC is a provider resource attached to an instance; the guest sees a corresponding interface through its driver. Record both views when mapping cloud resources to a Linux host.

A guest shows enp0s9 and lo.

  1. enp0s9 is a named attachment point, not a remote machine.
  2. Its address and prefix are configuration associated with that interface.
  3. lo supplies a host-local path. It does not represent an external network cable.

Practical troubleshooting

Symptom

An interface exists but has no IPv4 address.

Evidence that narrows the cause

Check link state and address configuration separately. IPv6 or link-layer traffic may still exist.

Next action and verification

Find the intended address assignment mechanism before assigning a guessed address.

Retest the original operation from the same source context. A successful test of a different endpoint or protocol does not establish that this symptom is resolved.
