Network addresses, broadcast addresses, and host ranges

Understand the idea

Learning target: Find the boundaries of a conventional IPv4 subnet and distinguish total addresses from host addresses.

Locate the conventional IPv4 boundaries

The network address has all host bits zero. The broadcast address has all host bits one. In a conventional multi-access IPv4 subnet, these identify the block and its directed broadcast rather than ordinary individual hosts. The intermediate addresses form the conventional host range.

Separate total from usable

A /26 has 64 total addresses. Under the conventional network-and-broadcast reservation model, 62 are host addresses. This formula does not apply unchanged to /31 point-to-point links, /32 host prefixes, IPv6, or cloud platform reservation policies. Always state the context before presenting a usable count.

Find the containing block first

For 192.168.1.150/26, blocks in the final octet begin at 0, 64, 128, and 192. The address lies in the block beginning at 128. The last address is 191, so the conventional host range is 129 through 190. An address ending in .0 or .255 is not automatically unusable under every prefix; use the actual host-bit boundary.

See the relationships

Work through one example

Calculate 10.0.4.70/27.

  1. A /27 contains 32 addresses and has final-octet boundaries at multiples of 32.
  2. 70 lies between 64 and 95 inclusive.
  3. The network is 10.0.4.64, the conventional broadcast is 10.0.4.95, and the host range is 10.0.4.65–10.0.4.94.

Practical troubleshooting

Symptom

An allocated host is the final address of its conventional subnet.

Evidence that narrows the cause

Calculate the boundary rather than examining only the decimal suffix.

Next action and verification

Choose an appropriate assignable address under the platform rules.

Retest the original operation from the same source context. A successful test of a different endpoint or protocol does not establish that this symptom is resolved.
