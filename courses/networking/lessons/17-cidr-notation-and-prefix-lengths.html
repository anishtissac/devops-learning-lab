Understand the idea

Learning target: Connect /24, /28, and other prefixes to masks, block sizes, and same-subnet comparisons.

CIDR counts leading bits

Classless Inter-Domain Routing notation writes an address and prefix length, such as 10.4.8.0/21. Classless means the explicit prefix controls interpretation; old Class A, B, and C assumptions are not a substitute for reading it. An IPv4 prefix can range from /0 through /32.

Calculate the total address count

For prefix p, there are 32 − p variable bits, so the block has 2^(32 − p) total addresses. A /24 has 256, a /25 has 128, and a /28 has 16. Assignable host count is a different question. Conventional IPv4 subnets, point-to-point links, host routes, and cloud platforms can use different reservation rules.

Compare prefixes carefully

An address with host bits set can be written with a prefix, such as 10.4.9.17/21. Its containing network is 10.4.8.0/21. Do not assume the written address is already the canonical network base. Prefix containment and overlap are arithmetic properties; reachability still requires the appropriate route and access configuration.

  2. The mask is 255.255.248.0, so the third octet groups in blocks of eight.

Practical troubleshooting

Symptom

A route or API rejects a noncanonical network input.

Evidence that narrows the cause

The written address has host bits set. Some tools canonicalise it; others require an aligned base.

Next action and verification

Calculate and supply the intended network prefix explicitly.

Retest the original operation from the same source context. A successful test of a different endpoint or protocol does not establish that this symptom is resolved.
