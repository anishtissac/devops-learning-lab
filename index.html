What is a network?

We’ll begin with the basic idea: what a network is, before we study interfaces and IP addresses.

Simple explanation

A device can be a laptop, phone, server, or router.
A network connects devices so they can exchange data.
The connection can use Wi-Fi, a cable, or a virtual connection in a cloud.
Devices use shared rules, called protocols, to send and receive data.
Key idea: A connection gives devices a path to communicate. Network settings and security rules can still control which data is allowed.

Where you’ll see networks

Linux or office

A laptop can connect to a local network through Wi-Fi or Ethernet.

Cloud

An application server and a database server can connect through a private cloud network, such as an OCI VCN or AWS VPC.

Network vs. Internet: A home Wi-Fi network is one network. The Internet is a very large system of connected networks.

Course roadmap
  1. Network foundations: networks, devices, interfaces, and IP addresses
  2. IP addressing: IPv4, IPv6, private and public addresses
  3. CIDR and subnet masks: prefixes and network/host parts
  4. Subnetting and VLSM: ranges, subnet sizes, and address planning
  5. Ports and connections: TCP, UDP, ports, and sockets
  6. Network services: DNS, HTTP/HTTPS, TLS, SSH, and ICMP
  7. Traffic delivery: gateways, routing, ARP, NAT, MTU, and firewalls
  8. Linux networking: commands and safe troubleshooting practice
  9. Cloud networking: VCN/VPC, subnets, routes, gateways, security rules, and load balancers
  10. Containers and Kubernetes: namespaces, bridges, Pod IPs, Services, and Ingress
  11. DevOps and AI: APIs, proxies, streaming, model endpoints, latency, and network troubleshooting
